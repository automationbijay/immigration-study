# Canada FSW 67-Point Calculator Project

## Overview
This project contains a data extraction script and a standalone reverse-engineered web calculator for the **Canadian Federal Skilled Worker (FSW) 67-Point System**. 

The goal of the project was to scrape the questionnaire structure and calculation point values from an existing immigration calculator and then recreate a clean, functioning, and dynamic interactive user interface based directly on that extracted data.

## Project Structure
- **`scrape_points.py`**: A Python script utilizing Playwright and BeautifulSoup to automate the browser, parse the HTML, and extract the FSW questionnaire data.
- **`fsw_67_points.json`**: The resulting output file generated by the python script. It contains the raw categories (e.g., Age, Experience, Education) and their corresponding point mappings.
- **`index.html`**: A fully functional, reverse-engineered Point Calculator built with HTML, CSS, and Vanilla JavaScript.

## Data Source
The base questionnaire structure and point allocation mappings were dynamically scraped from:
- **Source**: `https://www.siaimmigration.com/fsw-67point-calculator`

## How It Works

### 1. Data Scraping (`scrape_points.py`)
The scraping script operates as follows:
1. Uses **Playwright** in headless mode to navigate to the source URL and wait for the page and its tables to fully load.
2. Grabs the raw `innerHTML` of the page and passes it to **BeautifulSoup** for DOM parsing.
3. Iterates over `<select>` dropdowns and `<input type="radio">` buttons to extract:
   - The question / category title.
   - The descriptive text of the option (e.g., "18-35", "Master's degree").
   - The exact point value associated with selecting that option.
4. Cleans up whitespace formatting and saves the structured data as `fsw_67_points.json`.

### 2. The Calculator UI (`index.html`)
The frontend takes the data structure and builds the calculator dynamically:
- **Dynamic Rendering**: The JavaScript parses the JSON mapping to generate the DOM elements (dropdowns for Age/Experience/Language, radio buttons for Education, checkboxes for Adaptability).
- **Language Scoring**: The script maps IELTS band scores to CLB (Canadian Language Benchmarks) levels and awards points correctly (Max 24 points). The CLB texts were deliberately hidden from the UI for better UX, showing only raw IELTS scores.
- **Adaptability**: Adaptability allows multiple selections but strictly caps the maximum category score at 10 points.
- **Real-time Assessment**: An event listener recalculates the sum of all categories anytime an input changes, immediately updating the bottom sticky banner to reflect eligibility (Pass: >= 67, Fail: < 67).

## Setup & Execution
If you wish to re-run the scraper in the future to capture updated metrics:
1. Ensure you have Python installed.
2. Install the requirements:
   ```bash
   pip install playwright beautifulsoup4
   playwright install chromium
   ```
3. Run the script:
   ```bash
   python scrape_points.py
   ```
4. Open `index.html` in any modern web browser to view and use the calculator.
