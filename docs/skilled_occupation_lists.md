# Skilled Occupation Lists Rules

## Mutual Exclusivity
The Australian Department of Home Affairs structures the Skilled Occupation Lists so that a distinct occupation code sits exclusively on either the Medium and Long-term Strategic Skills List (MLTSSL), the Short-term Skilled Occupation List (STSOL), or the Regional Occupation List (ROL). An occupation cannot simultaneously be classified as purely medium-term (MLTSSL), short-term (STSOL), or regional-only (ROL).

## Visa Eligibility Mapping
While the lists themselves contain no intersecting occupations, there is overlap in the visas that occupations on these lists are eligible for:

* **MLTSSL** (212 occupations): Eligible to apply for Subclasses **189, 190, and 491**.
* **STSOL** (215 occupations): Eligible to apply for Subclasses **190 and 491**.
* **ROL** (77 occupations): Eligible to apply for Subclass **491** only.
